一、程序结构

一个 JS 程序由语句（statement）组成，语句以分号结尾；数据存放在变量中，配合注释让代码可读。

// 1. 变量与常量：用关键字声明并存储不同类型的数据
let yl_name = "姚琳";              // 字符串
const yl_age = 20;               // 数字（常量不可改）
let yl_score = 88;               // 数字
let yl_isPass = true;           // 布尔值
let yl_hobbies = ["绘画", "前端"]; // 数组
let yl_student = { name: yl_name, age: yl_age }; // 对象

// 2. 表达式与运算符
let yl_total = yl_score + 12;    // 算术运算
let yl_result = yl_total >= 60; // 比较运算

// 3. 语句（以分号结尾，顺序执行）
console.log(yl_name + " 总分：" + yl_total);

二、循环

循环用于重复执行一段代码：for 适合确定次数，while 先判断后执行，do-while 至少执行一次。

for 循环 · 1~100 累加

确定次数时最常用，含初始值、条件、步进三部分。

while 循环 · 打印偶数

先判断条件再执行，条件不满足则跳过。

do-while 循环 · 至少一次

先执行再判断，即使条件为假也执行一次。

嵌套 for · 九九乘法表

外层控制行、内层控制列，两两相乘。

三、条件

条件判断让程序根据不同的情况执行不同的代码分支。

if ... else if ... else · 成绩等级

输入 0~100 的分数，输出对应等级。

switch · 星期判断

根据星期几判断是工作日还是周末（红色为周末）。

三元运算符 · 奇偶判断

输入任意整数，判断奇偶（条件 ? 真 : 假）。
