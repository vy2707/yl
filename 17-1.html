一、什么是 JSON

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，用纯文本表示数据，方便在不同系统、前后端之间传递。它看起来像 JavaScript 对象，但规则更严格。

全称与定位

JavaScript Object Notation，一种数据交换格式，与语言无关。

键名必须加双引号

JSON 里的"键"和"字符串值"都必须用双引号，不能用单引号。

支持的数据类型

字符串、数字、布尔值、null、数组 []、对象 {}。

用途广泛

接口返回数据、配置文件、本地存储，几乎都用 JSON 传递。
