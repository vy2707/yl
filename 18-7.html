Three.js 三维演示

使用本地 Three.js 渲染两个三维场景：旋转的彩色立方体与环面纽结

姚琳 · 18-7
← 返回首页 index.html

一、旋转彩色立方体

使用 BoxGeometry 与六个不同颜色的 MeshStandardMaterial 构建立方体，叠加 EdgesGeometry 描边，在平行光 + 环境光下自动旋转。

拖动可手动旋转，松开后带惯性继续旋转。

二、旋转环面纽结

使用 TorusKnotGeometry 与 MeshNormalMaterial 构建环面纽结，法线材质随面朝向呈现彩虹渐变色，无需灯光即可看清立体结构。

拖动可手动旋转，松开后带惯性继续旋转。

三、实现要点

1. 引入本地 cdn/three/three.min.js，不依赖 CDN 在线加载；
2. 用 Scene + PerspectiveCamera + WebGLRenderer 搭建三维场景；
3. 用 BoxGeometry、TorusKnotGeometry 等几何体与材质创建 Mesh；
4. 通过 requestAnimationFrame 循环更新旋转并调用 renderer.render() 实现动画，监听鼠标事件实现拖拽旋转。
