一、智能客服系统流程图

用 Mermaid 的 flowchart 语法描述智能客服的完整业务流：从用户提问、意图识别、知识库检索，到命中答案回复或转人工，以及满意度评价后的知识沉淀反馈。

flowchart TD
    A([用户进入智能客服]) --> B[输入咨询问题]
    B --> C[意图识别与实体抽取]
    C --> D[语义检索知识库]
    D --> E{是否命中答案}
    E -- 是 --> F[大模型生成答案]
    E -- 否 --> G[转接人工客服]
    F --> H[回复用户]
    G --> H
    H --> I[满意度评价]
    I -. 反馈沉淀 .-> D

二、智能客服系统 E-R 图

用 Mermaid 的 erDiagram 语法描述智能客服系统的实体关系：用户、会话、客服人员、评价、知识条目与知识分类六类实体及其主键、属性和关联关系。

erDiagram
    USER ||--o{ SESSION : 发起
    AGENT ||--o{ SESSION : 处理
    SESSION ||--o| RATING : 获得
    SESSION }o--o{ KNOWLEDGE : 引用
    CATEGORY ||--o{ KNOWLEDGE : 属于

    USER {
        int 用户ID PK
        string 用户名
        string 手机号
        string 会员等级
    }
    SESSION {
        int 会话ID PK
        string 问题内容
        datetime 开始时间
        string 接入渠道
    }
    AGENT {
        int 客服ID PK
        string 姓名
        string 技能组
    }
    RATING {
        int 评价ID PK
        int 评分
        string 反馈内容
    }
    KNOWLEDGE {
        int 条目ID PK
        string 标题
        string 内容
        string 语义向量
    }
    CATEGORY {
        int 分类ID PK
        string 分类名称
    }

三、实现要点

1. 引入本地 cdn/mermaid/mermaid.min.js，不依赖 CDN 在线加载；
2. 用 mermaid.initialize() 配置主题，再调用 mermaid.run() 渲染页面中所有 .mermaid 元素；
3. 流程图采用 flowchart TD 自上而下布局，用 {菱形} 表示判断、([圆角]) 表示起止；
4. E-R 图采用 erDiagram 语法，||--o{ 表示一对多、}o--o{ 表示多对多，并声明主键 PK。
