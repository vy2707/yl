一、6 种数据类型总览

数据类型 说明 示例 typeof 结果
String 字符串，由引号包裹的文本 "姚琳"、'630' "string"
Number 数值，含整数、浮点数、NaN、Infinity 100、3.14、NaN "number"
Boolean 布尔值，只有真和假两个值 true、false "boolean"
Undefined 已声明但未赋值的变量的默认值 var yl_x; "undefined"
Null 空值，表示“没有对象” null "object"（历史遗留）
Object 对象，含数组、函数等引用类型 {}、[]、function(){} "object" / "function"

三、注意事项

typeof null === "object" 这是 JavaScript 早期实现的历史遗留问题，判断空值应使用 === null。
函数是特殊的 Object typeof function(){} 返回 "function"，但函数本质上仍属于对象类型。
NaN 属于 Number NaN 表示“非数字”，但它的数据类型仍然是 "number"。
未赋值不等于未声明 只声明未赋值的变量是 undefined；typeof 检测未声明变量也返回 "undefined"，但直接使用未声明变量会报错。
